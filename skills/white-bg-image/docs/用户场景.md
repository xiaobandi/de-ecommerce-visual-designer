# 用户场景

按「谁 → 什么情况下 → 说什么 → 得到什么 → 注意什么」组织。每个场景都能照着跑一遍。

---

> ⚠️ 本技能尚未填写真实场景（`scenarios`），下面为**通用推导**，信息量有限。

## 场景一 · 使用者的日常用法

- **角色**：使用者
- **触发时机**：需要「白底图生成」这件事有结果的时候
- **他会说**：`用 white-bg-image 帮我白底图`
- **需要准备**：商品原图
- **拿到什么**：白底图 或 处理参数说明
- **容易踩的坑**：透明与反光材质是抠图难点，需标注人工复核

---

## 场景二 · 换成你自己的材料

同一句话，把材料换成你手头的真实数据即可：

```text
用 white-bg-image 处理下面这份材料：
<粘贴你的内容 / 贴文件路径>
```

**输入结构不要改**：字段名变了，脚本会读不到；缺字段时应当被明确告知缺什么，而不是猜。

| 字段 | 必填 | 说明 |
|---|---|---|
| 商品原图 | ✅ | 缺失会导致输出不可用 |
| 目标平台白底规范 | ⬜ | 有则更好 |
| 是否需要阴影 | ⬜ | 有则更好 |

---

## 场景三 · 边界情况（重要）

这几条写清楚做不到什么，比列一堆能力更有用：

- 不改动商品本身的外观特征（保真是底线）
