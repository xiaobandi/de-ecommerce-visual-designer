## 场景一 · 电商 AI 商品视觉的日常用法

- **角色**：电商 AI 商品视觉
- **触发时机**：需要「平台规格适配（图像）」这件事有结果的时候
- **他会说**：`用 platform-spec-adapter 帮我尺寸适配`
- **需要准备**：主素材（并说明原始尺寸）
- **拿到什么**：适配参数表 + 风险提示
- **容易踩的坑**：方形裁成竖版通常要重构图，直接拉伸会变形——需提前告知

---

## 场景二 · 换成你自己的材料

同一句话，把材料换成你手头的真实数据即可：

```text
用 platform-spec-adapter 处理下面这份材料：
<粘贴你的内容 / 贴文件路径>
```

**输入结构不要改**：字段名变了，脚本会读不到；缺字段时应当被明确告知缺什么，而不是猜。

| 字段 | 必填 | 说明 |
|---|---|---|
| 主素材（并说明原始尺寸） | ✅ | 缺失会导致输出不可用 |
| 目标平台清单 | ⬜ | 有则更好 |
| 是否允许裁切 | ⬜ | 有则更好 |
