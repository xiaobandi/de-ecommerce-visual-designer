# 05 · 验收与测试

## 怎么跑

```bash
python3 tests/run.py                       # 全量
python3 tests/run.py --suite structure     # 只跑结构完备性
python3 tests/run.py --suite contract      # 只跑契约闭环
python3 tests/run.py --suite scenario      # 只跑多场景用例
python3 tests/run.py --suite script        # 只跑共享脚本内嵌自测
python3 tests/run.py --suite doc           # 只跑文档命令可执行性
python3 tests/run.py --suite compliance    # 只跑纪律与合规
python3 tests/run.py --json reports/local.json
```

## 六类测试覆盖什么

| 套件 | 覆盖 |
|---|---|
| structure | 必需文件、目录名与 frontmatter name 一致、链接可达、YAML 可解析 |
| contract | 工作流调用的技能可解析、依赖版本可解析、无重复物理存放 |
| scenario | 正向 / 缺输入 / 越界 / 数值纪律 / 闸门 / 降级 |
| script | 共享脚本内嵌自测（确定性断言，不需要 LLM；副本漂移会当场暴露） |
| doc | 文档里写出来的命令照抄必须跑得通：脚本路径可达、校验命令写明 cwd |
| compliance | 红线声明齐备、无密钥、无真实 PII、无本机绝对路径、许可与署名齐备 |
