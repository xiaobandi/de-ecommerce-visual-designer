# 02 · 使用教程

## 场景一：首次跑通（10 分钟）

1. 打开对话，粘贴系统提示词（`persona/system-prompt.md` 代码块）
2. 说：「加载 de-ecommerce-visual-designer 的技能目录」
3. 用一句真实需求试跑「商品图批量生成与质检」：

```text
帮我跑「商品图批量生成与质检」：<粘贴你的材料>
```

4. 检查产出是否齐备四要素：输入来源 / 产出内容 / 依据与结论 / 未决·待填

## 场景二：日常单点调用

不需要把整条工作流跑完，直接点名技能更快：

```text
用「平台规格适配」处理这份材料：<材料>
```

## 场景三：定时跑

工作流 `wf-ecom-visual-batch-gen-qc` 的触发方式是
「人工」。
在支持定时的环境里，把它挂成对应频率的定时任务；产出会停在
「待人工确认」，不会自动对外发布。

## 场景四：接自有数据

1. 在 `connectors/bindings.yaml` 里把对应连接器 `status` 改为 `bound`
2. 通过环境变量注入凭证
3. 跑 `python3 tests/run.py --suite compliance` 确认没有把凭证写进产出

## 使用纪律（必须遵守）

- ✅ 材料里没有的数字，让它写 `<待填>`
- ✅ 所有对外内容人工确认后再发
- ❌ 不要把别的店铺/账号的数据混进来（业务红线第 10 条）
- ❌ 不要要求它绕过边界——边界就是产品的一部分
