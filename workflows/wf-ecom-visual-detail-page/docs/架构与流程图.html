三、脚本与模型的分工

分工原则：把确定的事交给确定的方法，把需要读懂语境的事交给模型。

环节承担者为什么
机械处理（扫描、渲染、打标、计算）脚本可复现、可测试、零成本、不怕漏

最终交付判定人合规与承诺不能由机器签字

五、扩展指南

5.1 增加一个执行步骤

  1. 在 SKILL.md 的 ## 执行步骤 里追加一步，写明输入、产出、失败怎么办
  2. 如果是机械环节，写成脚本放进 scripts/，并在步骤前加 [脚本] 标记
  3. 同步更新本文件的 Mermaid 源码与 README.md 的输出契约
  4. 在技能库根目录重新跑平台兼容校验：python3 tests/run.py

    5.2 换掉/新增脚本

    脚本约定三条（保持不变才能被安全替换）：

    1. 零第三方依赖，只用 Python 标准库
    2. 文件/stdin 进，stdout 出，不用交互式输入
    3. 退出码语义：0 通过 / 1 警告 / 2 阻断

    5.3 移植到新平台

    本技能正文里没有出现任何平台名，平台差异全部下沉到平台安装章节。移植时只改安装说明，不改执行步骤。
    新增平台时请把差异写进 docs/使用手册.md 的「各平台差异」表，不要写进 SKILL.md。
