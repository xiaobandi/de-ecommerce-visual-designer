使用手册

技能：平台合规预审（wf-ecom-visual-compliance-precheck）　·　L2 工作流技能　·　v1.0.0

一、环境要求

项要求
Agent 平台WorkBuddy / ChatGPT / DeepSeek Harness / Kimi Work / 豆包工作中任一
Python3.8+（仅当本技能自带脚本时需要；纯对话使用不需要）
第三方依赖无。脚本只使用标准库
网络无强制要求；Excel/图片类处理在本地完成

二、安装

2.1 目录放置（推荐）

cp -r wf-ecom-visual-compliance-precheck ~/.workbuddy/skills/          # WorkBuddy / 通用

2.2 各平台差异

平台方式注意事项
WorkBuddy放到 ~/.workbuddy/skills/支持自动触发，也可显式点名
ChatGPT上传 zip需账号支持 Skills
DeepSeek Harness新建技能 安装:<repo-url>需要仓库可访问
Kimi Work上传 zip / 放目录不会自动调用，必须显式点名技能
豆包工作新建技能 安装:<repo-url>触发词识别依赖 description 质量

2.3 安装后自检

# 在技能库根目录执行（技能目录内没有 tools/）
python3 tests/run.py

校验项：目录名与 name 一致、只使用标准字段、正文不含平台专有工具名、触发词中英双语且信息量足够。任一项不通过，技能在部分平台会静默不加载。


三、快速上手


3.1 纯对话方式（零安装）


用 wf-ecom-visual-compliance-precheck 技能：<把你的材料贴进来>


3.2 脚本方式（推荐，结果可复现）

把脚本当作一个纯函数使用：stdin/文件进，stdout/文件出，退出码表达判定结果。因此可以直接嵌进任何编排器（Agent、CI、定时任务）。

退出码含义典型场景
