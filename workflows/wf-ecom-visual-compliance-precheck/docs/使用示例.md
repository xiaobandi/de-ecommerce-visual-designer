# 使用示例

技能：**平台合规预审**（`wf-ecom-visual-compliance-precheck`）

> ⚠️ **本技能的真实效果示例尚未补齐**：以下仅为输入 / 输出契约（**不构成效果证据**）与平台兼容性验证结果。发布前须补至少 3 组「真实输入 → 实际产出」。

---

## 示例一 · 标准用法（真实运行）

```bash
python3 ../../tools/compliance_scan.py --file examples/input/draft.txt --platform 淘宝
```

**真实输出**：

```console
目标平台：淘宝　词表版本：2026.09-baseline
结论：阻断
  - 医疗功效 命中 1 处
  - 平台引流 命中 1 处
  - 极限词 命中 5 处
AI 味评分：0/100
命中总数：7
  [极限词] 全网最低价, 100%, 国家级认证, 绝对, 最划算
  [医疗功效] 治失眠
  [平台引流] 加V
→ 命中高危，不得直接对外发布；逐条替换后重扫。
```

> 高危文案被判定为「阻断」——退出码 2，流水线因此拦住发布

> **注意**：退出码非 0 是**设计行为**（命中高危即阻断），不是报错。CI 里应据此中断发布。

## 示例二 · 用你自己的材料

```bash
python3 ../../tools/compliance_scan.py --file /path/to/your-data/draft.txt --platform 淘宝
```

把 `examples/input/` 下的文件换成你的真实材料即可；**输入结构不要改**，改了字段名脚本会读不到。

---

## 示例三 · 嵌进自动化链路

```bash
set -e
python3 ../../tools/compliance_scan.py --file examples/input/draft.txt --platform 淘宝 || exit 2   # 非零即阻断
```

脚本是纯函数：文件/stdin 进、stdout 出、退出码表达判定，因此可以被 CI、定时任务或上层工作流直接编排。
