# 使用手册

技能：**多平台规格一键适配**（`wf-ecom-visual-spec-adapt`）　·　L2 工作流技能　·　v1.0.0

---

## 一、环境要求

| 项 | 要求 |
|---|---|
| Agent 平台 | WorkBuddy / ChatGPT / DeepSeek Harness / Kimi Work / 豆包工作中任一 |
| Python | 3.8+（**仅当本技能自带脚本时需要**；纯对话使用不需要） |
| 第三方依赖 | 无（纯提示词技能） |
| 网络 | 无强制要求；Excel/图片类处理在本地完成 |

## 二、安装

### 2.1 目录放置（推荐）

```bash
cp -r wf-ecom-visual-spec-adapt ~/.workbuddy/skills/          # WorkBuddy / 通用
```

### 2.2 各平台差异

| 平台 | 方式 | 注意事项 |
|---|---|---|
| WorkBuddy | 放到 `~/.workbuddy/skills/` | 支持自动触发，也可显式点名 |
| ChatGPT | 上传 zip | 需账号支持 Skills |
| DeepSeek Harness | `新建技能 安装:<repo-url>` | 需要仓库可访问 |
| Kimi Work | 上传 zip / 放目录 | **不会自动调用**，必须显式点名技能 |
| 豆包工作 | `新建技能 安装:<repo-url>` | 触发词识别依赖 description 质量 |

### 2.3 安装后自检

```bash
# 在技能库根目录执行（技能目录内没有 tools/）
python3 tests/run.py
```

校验项：目录名与 `name` 一致、只使用标准字段、正文不含平台专有工具名、触发词中英双语且信息量足够。**任一项不通过，技能在部分平台会静默不加载。**

## 三、快速上手

### 3.1 纯对话方式（零安装）

```text
用 wf-ecom-visual-spec-adapt 技能：<把你的材料贴进来>
```

## 四、参数总表

### 4.1 输入字段

| 字段 | 必填 | 说明 |
|---|---|---|
| 流程起始材料（见执行步骤第 1 步） | ✅ | 缺失会导致早退或输出不可用 |
| 用户身份与目标渠道/平台 | ✅ | 缺失会导致早退或输出不可用 |
| 历史产出 | ⬜ | 提升质量，缺失不阻塞 |
| 账号人设 | ⬜ | 提升质量，缺失不阻塞 |
| 渠道规则 | ⬜ | 提升质量，缺失不阻塞 |
| 上一周期数据 | ⬜ | 提升质量，缺失不阻塞 |

### 4.2 触发词

| 语言 | 触发词 |
|---|---|
| 中文 | 多平台规格一键适配、电商 AI 商品视觉 |
| 英文 | wf ecom visual spec adapt |

## 五、输出物说明

**多平台规格一键适配交付物（按执行步骤逐步产出）**

```markdown
# 多平台规格一键适配 — 交付物
> 所属员工：电商 AI 商品视觉　触发：事件　阶段：P1

1. **主素材**（产出：平台规格适配（图像））
2. **各平台尺寸适配**（产出：本步结论）

## 结论与风险
## 用了哪条降级路径（若发生）
```

交付前逐条核对：

- [ ] 关键元素（商品主体、文字）在每个比例下都落在安全区内
- [ ] 各步产出按顺序衔接，链路无断点
- [ ] 缺料时显式停下来问，未用假设填补
